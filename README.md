# 📊 Customer Intelligence & Financial Analytics Dashboard

This project is an end-to-end Business Analytics solution built using **Python**, **MySQL**, and **Power BI**. It analyzes customer purchasing behavior and generates actionable business insights through interactive dashboards.

## 🚀 Technologies Used

- Python (Pandas, NumPy)
- MySQL
- Power BI
- Git & GitHub

## 📂 Project Workflow

1. Data Cleaning and Preprocessing using Python
2. Feature Engineering
3. Business Analysis using MySQL
4. Interactive Dashboard Creation in Power BI

## 📌 Features

- Customer Segmentation
- Customer Value Tier Analysis
- Customer Health Score
- Revenue Analysis
- Revenue at Risk Analysis
- Purchase Frequency Analysis
- Interactive Dashboard with Filters

## 📊 Dashboard KPIs

- Total Customers
- Total Revenue
- Average Customer Lifetime Value (CLV)
- Average Customer Health Score
- Total Revenue at Risk

## 📈 Dashboard Visuals

- Revenue by Customer Segment
- Customer Distribution by Segment
- Revenue by Customer Value Tier
- Average Customer Health Score
- Revenue at Risk by Customer Segment
